# Power BI report handover checklist

**Report not supplied or validated yet.** After upload:
- Document actual pages, filters, slicers and KPIs; don't assume the resume description exactly matches the PBIX.
- Review model grain, relationships, active/inactive filters and DAX.
- Confirm datasource paths, privacy and refresh permissions.
- Test all slicers, cross-filtering, drill-through and totals in Power BI Desktop.
- Export actual screenshots only after verifying they match the report.
- Explain any differences from SQL metrics in [METRICS.md](METRICS.md).
