# Upload the actual project files

1. Upload original, authorized CSV/XLSX files to [data/raw](../data/raw/README.md) and audited exports to [data/cleaned](../data/cleaned/README.md).
2. Upload original .sql scripts under [sql](../sql/README.md), using unique filenames (keep existing illustrative starter files so provenance remains clear).
3. Upload the actual PBIX to [powerbi](../powerbi/README.md), then optionally add genuine report screenshots.
4. Fill in [ASSET_MANIFEST.md](ASSET_MANIFEST.md) and [PROJECT_EVIDENCE.md](PROJECT_EVIDENCE.md) with verified provenance.
5. Reconcile source schema, update examples, run quality checks, execute SQL in a development environment and test the PBIX locally.
6. Write a findings section in the project README **only** with real, corroborated figures.

**Do not commit secrets, sensitive customer records or private employer/client data.** GitHub file-upload UI has size limitations; use Git or appropriate large-file storage when needed.
