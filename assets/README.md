## UrbanCart – E-Commerce Sales & Customer Analytics

An end-to-end data analytics project focused on understanding e-commerce sales performance, customer behaviour, product trends, and business operations through SQL analysis and interactive Power BI dashboards.

### Dashboard Preview

#### 1. UrbanCart Performance Dashboard – Overview


This page provides an overview of business performance through key metrics and visualisations, including:

- Total Revenue, Total Orders, Average Order Value, Return Rate, and Total Customers.
- Monthly Revenue Trend.
- Revenue by Region.
- Revenue by Product Category.
- Interactive filters for Region, Channel, and Customer Segment.

#### 2. Customer, Channel & Product Analysis


This page provides a more detailed view of:

- Channel Performance – Online vs Store.
- Customer Segment Performance – Regular, Premium, and VIP.
- Top-performing Products.
- Return Reasons and Return Analysis.

### Tools & Technologies

- **Microsoft Excel:** Data preparation and cleaning.
- **SQL Server (T-SQL):** Data analysis, joins, aggregations, CTEs, window functions, and reusable views.
- **Power BI:** Interactive dashboard development and data visualisation.
- **DAX:** KPI calculations and business metrics.
- **Power Query:** Data transformation.

### Project Objective

To transform raw e-commerce data into meaningful business insights and support data-driven decisions through structured SQL analysis and interactive business intelligence dashboards.
